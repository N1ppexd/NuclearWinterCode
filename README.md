# NuclearWinterCode
Only the code from the 2023 nuclear winter game made in Pelifarmi


# Made in 2023

I made all of this code in 2023 in Pelifarmi, during 4 weeks.
I created a terrain generation system, camera movement systems,
player movement systems, random event system dice roller system, and a fog of war system and so much more.

Because I only had 4 weeks, The end result didn't end up being perfect, but I'm proud of what I was able to do iin 4 weeks. And this was before the AI got great at coding.

I have since improved, and I no longer write weird comments with cursewords


I could only make the code public because it was made by me, and the rest of the project had asset store assets 
that can't be publiced in a public repo
